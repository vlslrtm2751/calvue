# s-calendar i18n (ko/en) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make all library-owned UI text and date/time formatting locale-switchable with built-in Korean (`ko`) and English (`en`) catalogs plus a partial `messages` override, preserving the current Korean output byte-for-byte.

**Architecture:** A `CalMessages` catalog (static strings + `weekdaysShort` array + locale-specific formatter functions) is resolved from `locale` + optional `messages` override in the two root components. The resolved catalog reaches deeply-nested internal components via Vue `provide`/`inject` (`useCalI18n()`), and reaches the `useCalendarGrid` title via an added parameter. The library never touches dayjs's locale — formatters compose locale-neutral dayjs numeric tokens with catalog arrays, so rendering is deterministic regardless of the consumer's dayjs setup.

**Tech Stack:** Vue 3.4 `<script setup>`, TypeScript (strict, `verbatimModuleSyntax`), dayjs, `@vueuse/core`; Vite + `vite-plugin-dts`; `unplugin-auto-import` (Vue/VueUse/dayjs globals) + `unplugin-vue-components` (auto-registered `src/components/**` by kebab tag).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-05-i18n-design.md` (authoritative).
- No new runtime deps. Peer deps only: `vue ^3.4`, `dayjs ^1.11`, `@vueuse/core ^11`.
- **ko output must be byte-for-byte identical to current behavior** (except the pre-existing weekday-token bug the spec fixes: week/day headers and day-view title weekday now come from `weekdaysShort`).
- The library must NOT call `dayjs.locale(...)` (global) or `dayjs(x).locale(...)` (instance) anywhere. Weekday/month names + all language strings come only from the catalog; dayjs is used only for numeric tokens `YYYY M D H m HH mm` and date keys.
- `default locale = 'ko'`. Unknown locale string falls back to the `ko` catalog, then `messages` merges over it.
- `messages` merge = shallow, top-level key granularity: `{ ...base, ...overrides }`.
- No test framework exists and none is being added. Per-task verification is `yarn typecheck` (must exit 0) + targeted `grep`. Final task adds a manual playground smoke.
- `verbatimModuleSyntax: true` — type-only imports use `import type`. Exported functions/consts whose signatures name `Ref`/`InjectionKey`/`CalMessages` MUST import those types explicitly (auto-import does not make Vue *types* nameable in emitted `.d.ts`; a missing explicit type import causes TS4078 under `declaration: true`).
- All internal imports are relative paths (no `@/` alias). File depth: `src/composables/*` and `src/i18n/*` → `../types`; `src/components/*.vue` → `../types` / `../composables/x` / `../i18n/x`; `src/components/internal/*.vue` → `../../types` / `../../composables/x` / `../../i18n/x`.
- Branch: work on `extract-cal-library` (do not create branches). Package manager: yarn.

- **Create** `src/i18n/messages.ts` — `ko`/`en` built-in `CalMessages` catalogs, internal `monthsShort`/`monthsFull` (en only), `resolveMessages(locale, overrides?)`. Holds the eventTime/dayLabel/gridTimeLabel/title formatter logic (migrated from the deleted `format.ts`, per-locale).
- **Create** `src/composables/use-cal-i18n.ts` — `CAL_I18N` injection key (`InjectionKey<Ref<CalMessages>>`) and `useCalI18n(): Ref<CalMessages>` (fallback default = `ko`).

- **Modify** `src/index.ts` — export `CalMessages` type.

- **Modify** roots `src/components/cal-calendar.vue`, `src/components/cal-mini-month.vue` — resolve catalog; cal-calendar `provide`s it (has i18n-consuming descendants); both feed it to `useCalendarGrid` and localize their own text. **Task ordering rationale:** infrastructure (types → catalogs → composable → grid) lands first with everything still compiling (new code unused, `messages` param optional with `ko` default). Then consumers migrate one at a time. `format.ts` is deleted only in Task 11, after its last consumer switches — so `yarn typecheck` stays green after every task.

```ts
import type { Dayjs } from 'dayjs';
import type { CalEvent, CalMessages } from '../types';

// ─── ko helpers (현 format.ts / use-calendar-grid.ts 로직 그대로) ──────────────
const KO_WD = ['일', '월', '화', '수', '목', '금', '토'];

function koEventTime(d: Dayjs): string {
  const h = d.hour();
  const m = d.minute();
  const ampm = h < 12 ? '오전' : '오후';
  const h12 = h % 12 === 0 ? 12 : h % 12;
  return m === 0 ? `${ampm} ${h12}시` : `${ampm} ${h12}:${String(m).padStart(2, '0')}`;
}

function koDayLabel(ev: CalEvent, day: Dayjs): string {
  if (ev.allDay) return '종일';
  const d = day.startOf('day');
  const startsHere = ev.start.startOf('day').isSame(d);
  const endsHere = ev.end.subtract(1, 'millisecond').startOf('day').isSame(d);
  if (startsHere && endsHere) return `${ev.start.format('HH:mm')}–${ev.end.format('HH:mm')}`;
  if (startsHere) return koEventTime(ev.start);
  if (endsHere) return `${koEventTime(ev.end)} 종료`;
  return '종일';
}

function koGridTimeLabel(ev: CalEvent, day: Dayjs): string {
  if (ev.allDay) return '종일';
  const d = day.startOf('day');
  const startsHere = ev.start.startOf('day').isSame(d);
  const endsHere = ev.end.subtract(1, 'millisecond').startOf('day').isSame(d);
  if (startsHere && endsHere) return `${ev.start.format('HH:mm')}–${ev.end.format('HH:mm')}`;
  if (startsHere) return `${ev.start.format('HH:mm')}~`;
  if (endsHere) return `~${ev.end.format('HH:mm')}`;
  return '종일';
}

function koWeekTitle(s: Dayjs, e: Dayjs): string {
  if (s.year() !== e.year()) return `${s.format('YYYY년 M월 D일')} – ${e.format('YYYY년 M월 D일')}`;
  return s.month() === e.month()
    ? `${s.format('YYYY년 M월 D')}–${e.format('D일')}`
    : `${s.format('YYYY년 M월 D일')} – ${e.format('M월 D일')}`;
}

export const ko: CalMessages = {
  today: '오늘',
  prev: '이전',
  next: '다음',
  viewDay: '일',
  viewWeek: '주',

  overlapCount: (n) => `겹친 일정 ${n}건`,

  monthTitle: (d) => d.format('YYYY년 M월'),
  dayTitle: (d) => `${d.format('YYYY년 M월 D일')} (${KO_WD[d.day()]})`,

  eventTime: koEventTime,
  dayLabel: koDayLabel,
  gridTimeLabel: koGridTimeLabel,
  popoverDate: (d) => `${d.format('M월 D일')} (${KO_WD[d.day()]})`,

// ─── en helpers ───────────────────────────────────────────────────────────────
const EN_WD = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
const EN_MON_SHORT = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
const EN_MON_FULL = [
  'January', 'February', 'March', 'April', 'May', 'June',
  'July', 'August', 'September', 'October', 'November', 'December'

function enEventTime(d: Dayjs): string {
  const h = d.hour();
  const m = d.minute();
  const ampm = h < 12 ? 'AM' : 'PM';
  const h12 = h % 12 === 0 ? 12 : h % 12;
  return m === 0 ? `${h12} ${ampm}` : `${h12}:${String(m).padStart(2, '0')} ${ampm}`;
}

function enDayLabel(ev: CalEvent, day: Dayjs): string {
  if (ev.allDay) return 'All day';
  const d = day.startOf('day');
  const startsHere = ev.start.startOf('day').isSame(d);
  const endsHere = ev.end.subtract(1, 'millisecond').startOf('day').isSame(d);
  if (startsHere && endsHere) return `${ev.start.format('HH:mm')}–${ev.end.format('HH:mm')}`;
  if (startsHere) return enEventTime(ev.start);
  if (endsHere) return `${enEventTime(ev.end)} ends`;
  return 'All day';
}

function enGridTimeLabel(ev: CalEvent, day: Dayjs): string {
  if (ev.allDay) return 'All day';
  const d = day.startOf('day');
  const startsHere = ev.start.startOf('day').isSame(d);
  const endsHere = ev.end.subtract(1, 'millisecond').startOf('day').isSame(d);
  if (startsHere && endsHere) return `${ev.start.format('HH:mm')}–${ev.end.format('HH:mm')}`;
  if (startsHere) return `${ev.start.format('HH:mm')}~`;
  if (endsHere) return `~${ev.end.format('HH:mm')}`;
  return 'All day';
}

function enWeekTitle(s: Dayjs, e: Dayjs): string {
  if (s.year() !== e.year()) {
    return `${EN_MON_SHORT[s.month()]} ${s.date()}, ${s.year()} – ${EN_MON_SHORT[e.month()]} ${e.date()}, ${e.year()}`;
  }
  return s.month() === e.month()
    ? `${EN_MON_SHORT[s.month()]} ${s.date()}–${e.date()}, ${s.year()}`
    : `${EN_MON_SHORT[s.month()]} ${s.date()} – ${EN_MON_SHORT[e.month()]} ${e.date()}, ${s.year()}`;
}

export const en: CalMessages = {
  today: 'Today',
  prev: 'Previous',
  next: 'Next',
  viewDay: 'Day',
  viewWeek: 'Week',
  viewMonth: 'Month',
  viewList: 'List',
  allDay: 'All day',
  creator: 'Creator',
  start: 'Start',
  end: 'End',
  close: 'Close',
  noEvents: 'No events in this period.',
  todaySuffix: 'Today',
  more: (n) => `+${n} more`,
  overlapCount: (n) => `${n} overlapping`,
  weekdaysShort: EN_WD,
  monthTitle: (d) => `${EN_MON_FULL[d.month()]} ${d.year()}`,
  dayTitle: (d) => `${EN_WD[d.day()]}, ${EN_MON_SHORT[d.month()]} ${d.date()}, ${d.year()}`,
  weekTitle: enWeekTitle,
  eventTime: enEventTime,
  dayLabel: enDayLabel,
  gridTimeLabel: enGridTimeLabel,
  popoverDate: (d) => `${EN_MON_SHORT[d.month()]} ${d.date()} (${EN_WD[d.day()]})`,
  listMonthHeader: (d) => `${EN_MON_FULL[d.month()]} ${d.year()}`
};

// ─── resolver ─────────────────────────────────────────────────────────────────
const BUILTINS: Record<string, CalMessages> = { ko, en };

/** locale로 내장 카탈로그 선택(미지원 → ko) 후 overrides를 키 단위 얕은 병합. */
export function resolveMessages(locale: string, overrides?: Partial<CalMessages>): CalMessages {
  const base = BUILTINS[locale] ?? ko;
  return overrides ? { ...base, ...overrides } : base;
}
```

**Interfaces:**

**Context:** `inject` and `ref` are auto-imported globals, but `InjectionKey` and `Ref` are *types* — they must be imported explicitly with `import type` or the emitted `.d.ts` fails with TS4078 (an exported `InjectionKey<...>` const and a function returning `Ref<...>` both name these types in their public signatures).

- [ ] **Step 1: Create `src/composables/use-cal-i18n.ts`**

```ts
import type { InjectionKey, Ref } from 'vue';
import type { CalMessages } from '../types';
import { ko } from '../i18n/messages';

/** 루트 컴포넌트가 resolved 카탈로그 ref를 provide, 내부 컴포넌트가 inject. */
export const CAL_I18N: InjectionKey<Ref<CalMessages>> = Symbol('cal-i18n');

// provider 없이 내부 컴포넌트를 단독 사용해도 안전하도록 ko 폴백 (모듈 공유 ref)
const KO_FALLBACK: Ref<CalMessages> = ref(ko);

/** 내부 컴포넌트에서 현재 로케일 카탈로그를 읽는다. */
export function useCalI18n(): Ref<CalMessages> {
  return inject(CAL_I18N, KO_FALLBACK);
}
```
