# calvue 0.2.0 Cleanup + CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스펙([2026-08-02-v0.2-cleanup-and-ci-design.md](../specs/2026-08-02-v0.2-cleanup-and-ci-design.md))대로 GitHub Actions CI를 추가하고, 죽은 API 3종을 제거하며 `CalEventChange` 페이로드 타입을 도입해 0.2.0을 준비한다.

**Architecture:** PR 2개 스택 — `ci-workflow` 브랜치(Task 1: 워크플로+배지+gitignore) 위에 `v0.2-api-cleanup` 브랜치(Task 2: API 정리)를 쌓는다. 사용자가 CI PR을 먼저 머지하면 API PR의 diff가 자체 변경만 남고 CI 검증을 받는다. 모든 제거 대상은 no-op이므로 런타임 동작 변화가 없다.

**Tech Stack:** GitHub Actions(ubuntu-latest, Node 22, yarn classic), Vue 3.4 + TS strict, Vite 5.

## Global Constraints

- 패키지 매니저 **yarn 전용** — `npm install` 금지.
- 커밋은 전부 pathspec 형식(`git commit -m "..." -- <files>`), `git add -A` 금지.
- **push/PR 생성/npm publish는 사용자 몫** — 커맨드와 링크만 제공(이 환경에서 권한 거부됨).
- CI Node 버전 **22** (로컬 v22.14.0과 일치).
- 완료 기준 grep: `src/`·`README.md`에서 `headerToolbar`·`rrule` 0건, `more: [`·`@more` 0건, README `현재 미적용`·`현재 미발생` 0건.
- 전제(이미 완료됨): `ci-workflow` 브랜치가 main(=origin/main `d7e7d0c`)에서 분기되어 스펙 커밋(`9db28d1`)을 담고 있음. 로컬 main은 origin과 일치.

  push:
