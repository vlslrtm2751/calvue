# s-calendar i18n (ko/en) 설계

**목적:** 라이브러리 UI 텍스트·날짜/시간 포맷을 로케일별로 전환 가능하게 한다. 한국어(ko)·영어(en) 내장 지원, 부분 오버라이드로 커스터마이징·제3 언어 확장 가능. 현재 하드코딩된 한국어 표기는 ko에서 **바이트 단위로 보존**한다.

**전제 상태:** 현재 라이브러리는 로케일 개념이 없다. `CalOptions.locale`(기본 `'ko'`)은 선언만 되고 **어디에서도 읽지 않는 죽은 필드**다. UI 문자열·요일 배열·날짜 포맷이 여러 파일에 한국어로 하드코딩돼 있다. 유일한 오버라이드는 `CalMiniOptions.weekdays`.

## 확정된 설계 결정 (브레인스토밍 승인)

1. **API 범위:** 내장 `ko`/`en` 카탈로그를 `locale`로 선택 + 선택적 `messages` **부분 오버라이드**(개별 키 교체, 제3 언어 공급).
2. **날짜 포맷:** **로케일별 포맷 기술자**(카탈로그가 포맷 문자열/함수를 보유). ko는 현 표기 그대로, en은 대응 영어판. dayjs 로케일 데이터는 사용하지 않는다.
3. **dayjs 결합:** **분리(자기완결형).** 라이브러리는 `dayjs.locale()`(전역)도, `dayjs(x).locale()`(인스턴스)도 호출하지 않는다. 요일/월 이름·언어 문자열은 전부 카탈로그에서, dayjs는 **숫자 토큰**(`YYYY`,`M`,`D`,`H`,`m`,`HH`,`mm`)에만 사용. 소비자의 dayjs 로케일 등록 여부와 무관하게 결정론적으로 렌더링.
4. **전달 방식:** `provide`/`inject` + `useCalI18n()` 컴포저블 (중첩 내부 컴포넌트에 prop 드릴링 회피).

## 공개 API 변경

기존 `CalOptions.locale: string`(죽은 필드)을 **실제 동작**시키고, 두 옵션 인터페이스에 `messages`를 추가한다.

```ts
interface CalOptions {
  // ...기존 필드 유지...
  locale: string;                  // 'ko' | 'en' 내장, 그 외는 messages로 공급. 기본 'ko'
  messages?: Partial<CalMessages>; // 선택: 선택 로케일 기본값 위에 키 단위 얕은 병합
}

interface CalMiniOptions {
  primaryColor: string;
  firstDay: number;
  weekdays: string[];              // 유지: 명시 시 로케일 weekdaysShort보다 우선(비파괴)
  locale: string;                  // 신규: 기본 'ko'
  messages?: Partial<CalMessages>; // 신규
}
```

**기본값:** `locale: 'ko'` — 현재 동작 하위호환 보존. 알 수 없는 `locale` 문자열은 `ko` 카탈로그로 폴백(+`messages` 병합).

**병합 규칙:** `resolved = { ...builtin[locale] ?? builtin.ko, ...messages }` — 최상위 키 단위 얕은 병합. 함수 값(포맷터)도 키 단위로 통째 교체 가능.

**공개 export 추가 (`src/index.ts`):** `export type { CalMessages }`.

## `CalMessages` 타입 (카탈로그 계약)

**정의 위치: `src/types.ts`** (공개 타입 계약이 모이는 곳; `CalEvent`와 같은 파일이라 순환 없음). `CalOptions.messages`가 `Partial<CalMessages>`를 참조하고, 카탈로그 상수는 `i18n/messages.ts`에서 이 타입을 import한다.

```ts
// src/types.ts (CalEvent와 동일 파일 — 별도 import 불필요)
export interface CalMessages {
  // 정적 UI 문자열
  today: string;      // 툴바 '오늘' 버튼
  prev: string;       // 이전 aria-label
  next: string;       // 다음 aria-label
  viewDay: string;    // 뷰 pill
  viewWeek: string;
  viewMonth: string;
  viewList: string;
  allDay: string;     // 종일 (시간그리드 코너 + dayLabel/gridTimeLabel 내부)
  creator: string;    // 툴팁 '작성자' 라벨
  start: string;      // 툴팁 '시작' 라벨
  end: string;        // 툴팁 '종료' 라벨
  close: string;      // 팝오버/클러스터 닫기 aria-label
  noEvents: string;   // 목록뷰 빈 상태
  todaySuffix: string; // 목록뷰 날짜의 '· 오늘' 접미
  more: (n: number) => string;         // 월뷰 '+N 더보기'
  overlapCount: (n: number) => string; // 시간그리드 '겹친 일정 N건'

  // 요일 이름 (일요일=index 0 기준, 7개)
  weekdaysShort: string[];

  // 로케일별 날짜/시간 포맷터 (dayjs 숫자 토큰 + 위 배열로 조립)
  monthTitle: (d: Dayjs) => string;              // 월뷰/미니 제목
  dayTitle: (d: Dayjs) => string;                // 일뷰 제목
  weekTitle: (start: Dayjs, end: Dayjs) => string; // 주뷰 제목 (범위)
  eventTime: (d: Dayjs) => string;               // 이벤트 시작 시각 표기
  dayLabel: (ev: CalEvent, day: Dayjs) => string;      // 월/목록 뷰 per-day 라벨
  gridTimeLabel: (ev: CalEvent, day: Dayjs) => string; // 주/일 뷰 per-day 라벨
  popoverDate: (d: Dayjs) => string;             // 월뷰 +N 팝오버 헤더 날짜
  listMonthHeader: (d: Dayjs) => string;         // 목록뷰 월 구분 헤더
}
```

### 내장 카탈로그 값

**ko (현재 동작 그대로 — 회귀 금지):**

| 키 | 값 |
|---|---|
| today | `'오늘'` |
| prev / next | `'이전'` / `'다음'` |
| viewDay/Week/Month/List | `'일'` / `'주'` / `'월'` / `'목록'` |
| allDay | `'종일'` |
| creator / start / end | `'작성자'` / `'시작'` / `'종료'` |
| close | `'닫기'` |
| noEvents | `'이 기간에 일정이 없습니다.'` |
| todaySuffix | `'오늘'` |
| more(n) | `` `+${n} 더보기` `` |
| overlapCount(n) | `` `겹친 일정 ${n}건` `` |
| weekdaysShort | `['일','월','화','수','목','금','토']` |
| monthTitle(d) | `d.format('YYYY년 M월')` |
| dayTitle(d) | `` `${d.format('YYYY년 M월 D일')} (${weekdaysShort[d.day()]})` `` (현 `(ddd)` 대체 — 아래 "숨은 버그" 참고) |
| weekTitle(s,e) | 현 `use-calendar-grid` 로직: 다른 해 `` `${s.format('YYYY년 M월 D일')} – ${e.format('YYYY년 M월 D일')}` ``; 같은 달 `` `${s.format('YYYY년 M월 D')}–${e.format('D일')}` ``; 그 외 `` `${s.format('YYYY년 M월 D일')} – ${e.format('M월 D일')}` `` |
| eventTime(d) | 현 `fmtEventTime`: `오전/오후` + 정각 `h시` / 그 외 `h:mm` (12시간제) |
| dayLabel(ev,day) | 현 `format.ts dayLabel` 로직 (종일 / `HH:mm–HH:mm` / `${eventTime} 종료` / 멀티데이 중간일 `종일`) |
| gridTimeLabel(ev,day) | 현 `format.ts gridTimeLabel` 로직 (`종일` / `HH:mm~` / `~HH:mm` / `HH:mm–HH:mm`) |
| popoverDate(d) | `` `${d.format('M월 D일')} (${weekdaysShort[d.day()]})` `` (현 `M월 D일 (dd)` 대체) |
| listMonthHeader(d) | `d.format('YYYY년 M월')` |

**en (대응 영어판):**

| 키 | 값 |
|---|---|
| today | `'Today'` |
| prev / next | `'Previous'` / `'Next'` |
| viewDay/Week/Month/List | `'Day'` / `'Week'` / `'Month'` / `'List'` |
| allDay | `'All day'` |
| creator / start / end | `'Creator'` / `'Start'` / `'End'` |
| close | `'Close'` |
| noEvents | `'No events in this period.'` |
| todaySuffix | `'Today'` |
| more(n) | `` `+${n} more` `` |
| overlapCount(n) | `` `${n} overlapping` `` |
| weekdaysShort | `['Sun','Mon','Tue','Wed','Thu','Fri','Sat']` |
| monthsShort (내부 헬퍼) | `['Jan',...,'Dec']` (en 포맷터 전용, 카탈로그 공개 키 아님) |
| monthTitle(d) | `` `${monthsFull[d.month()]} ${d.year()}` `` → `'July 2026'` |
| dayTitle(d) | `` `${weekdaysShort[d.day()]}, ${monthsShort[d.month()]} ${d.date()}, ${d.year()}` `` → `'Sat, Jul 5, 2026'` |
| weekTitle(s,e) | 다른 해 `` `${monthsShort[s]} ${s.date()}, ${s.year()} – ${monthsShort[e]} ${e.date()}, ${e.year()}` ``; 같은 달 `` `${monthsShort} ${s.date()}–${e.date()}, ${year}` ``; 그 외 `` `${monthsShort[s]} ${s.date()} – ${monthsShort[e]} ${e.date()}, ${year}` `` |
| eventTime(d) | 12시간제 `'9 AM'`(정각) / `'1:30 PM'` |
| dayLabel(ev,day) | ko와 동일 구조, `종일`→`'All day'`, `종료`→`'ends'` 접미(`` `${eventTime} ends` ``) |
| gridTimeLabel(ev,day) | ko와 동일 구조, `종일`→`'All day'`, `HH:mm~`/`~HH:mm` 형태 유지 |
| popoverDate(d) | `` `${monthsShort[d.month()]} ${d.date()} (${weekdaysShort[d.day()]})` `` → `'Jul 5 (Sat)'` |
| listMonthHeader(d) | `` `${monthsFull[d.month()]} ${d.year()}` `` |

> en 포맷터가 쓰는 `monthsShort`/`monthsFull` 배열은 `messages.ts` 내부 상수(카탈로그 공개 키 아님). ko 포맷터는 숫자 월이라 불필요.

## 아키텍처

### 신규 파일

- **`src/i18n/messages.ts`** — `ko`/`en` 내장 카탈로그 상수(`CalMessages`는 `../types`에서 import), `resolveMessages(locale, overrides?)` 병합 헬퍼, en 전용 내부 상수 `monthsShort`/`monthsFull`. (dayLabel/gridTimeLabel/eventTime의 ko·en 구현이 여기 산다 — 현 `format.ts` 로직 이관.)
- **`src/composables/use-cal-i18n.ts`** — `provide`/`inject` 심볼 키 `CAL_I18N` (`InjectionKey<Ref<CalMessages>>`)와 `useCalI18n(): Ref<CalMessages>`. `inject`에 **기본값 = ko 카탈로그 ref**를 주어, provider 없이 내부 컴포넌트를 단독 사용해도 안전.

### 루트 컴포넌트 (`cal-calendar.vue`, `cal-mini-month.vue`)

- `const resolved = computed(() => resolveMessages(opts.value.locale, opts.value.messages))`
- `provide(CAL_I18N, resolved)` — 하위 내부 컴포넌트가 `inject`로 소비.
- 자기 자신은 `provide`를 `inject`로 못 보므로, 루트의 자체 텍스트(툴바 오늘/이전/다음, 뷰 pill, 제목)는 **로컬 `resolved`를 직접** 참조.
- `cal-mini-month`: `weekdays` 최종값 = `opts.weekdays ?? resolved.value.weekdaysShort` (명시 오버라이드 우선). 제목은 `resolved` 기반.

### `useCalendarGrid` 리팩터링

- 시그니처에 `messages: Ref<CalMessages>` 추가: `useCalendarGrid(view, anchor, firstDay, weekends, messages)`.
- `title` computed을 `messages.value.monthTitle/dayTitle/weekTitle`로 생성 (현 하드코딩 제거). 두 루트가 각자 `resolved`를 전달 → DRY, 두 컴포넌트 모두 로케일 제목.
- `range/days/weeks` 반환은 불변.

### `format.ts` 처리

- `fmtEventTime`/`dayLabel`/`gridTimeLabel`은 로케일 종속 → `messages.ts`의 ko/en 카탈로그 함수로 이관. 독립 모듈 `format.ts`는 **삭제**.
- 소비처(cal-month-view, cal-time-grid, cal-event-bar, cal-time-event, cal-drag-ghost, cal-list-view)는 `const m = useCalI18n()` 후 `m.value.eventTime(d)` / `m.value.dayLabel(ev,day)` / `m.value.gridTimeLabel(ev,day)` 사용.

### 내부 컴포넌트 변경 인벤토리 (한국어 누출 0 보장 — 전수)

| 파일 | 현재 | 대체 |
|---|---|---|
| cal-calendar.vue | `오늘`/`이전`/`다음`, pill `일·주·월·목록` | `resolved` today/prev/next, viewDay/Week/Month/List |
| cal-mini-month.vue | 기본 weekdays `['일'..]`, 제목 | `weekdaysShort`(override 우선), `resolved` 제목 |
| cal-month-view.vue | DOW `['일'..]`, `M월 D일 (dd)`, `닫기`, `+N 더보기`, dot 시각, 팝오버 시각 | `weekdaysShort`, `popoverDate`, `close`, `more(n)`, `eventTime`, `dayLabel` |
| cal-time-grid.vue | 헤더 `format('dd')`, `종일`, `겹친 일정 N건`, `닫기`, per-day 라벨 | `weekdaysShort[day.day()]`, `allDay`, `overlapCount(n)`, `close`, `gridTimeLabel` |
| cal-list-view.vue | `['일'..]`, `오늘` 접미, 빈 상태, `YYYY년 M월` | `weekdaysShort`, `todaySuffix`, `noEvents`, `listMonthHeader` |
| cal-tooltip.vue | `작성자`/`시작`/`종료` 라벨 | `creator`/`start`/`end` |
| cal-event-bar.vue | `fmtEventTime` | `eventTime` |
| cal-time-event.vue | timeLabel(gridTimeLabel 유래) | 부모가 `gridTimeLabel` 주입 (현 구조 유지) |
| cal-drag-ghost.vue | `fmtEventTime` | `eventTime` |
| use-calendar-grid.ts | 제목 3종 하드코딩 | `messages` 포맷터 |

**언어중립이라 불변(누출 아님):** 데이터 키·표시용 숫자 포맷 `YYYY-MM-DD`, `HH:mm`, `'D'`, 툴팁 값 `YYYY-MM-DD HH:mm`. 코드 주석(미표시), 폰트 스택.

### 보너스로 고쳐지는 숨은 버그

현재 `cal-time-grid:7`의 `format('dd')`와 `use-calendar-grid:52`의 `(ddd)`는 dayjs 기본(영어) 로케일에 의존 → **한국어 모드인데도 주/일 헤더·일뷰 제목 요일이 영어("Sat")로 섞임**(예: `2026년 7월 5일 (Sat)`). 요일을 `weekdaysShort`에서 뽑으므로 ko=`(토)`, en=`(Sat)`로 **일관** 처리됨.

## 범위 밖 (정직성)

- **소비자 이벤트 데이터**(`title`, `extendedProps.creator`/`description` 값)는 소비자 소관 — en에서도 소비자가 넘긴 한국어는 그대로 표시.
- 코드 주석·폰트 스택(`Pretendard`→ en 시스템 폰트 폴백)은 표시 텍스트 아님.
- **dayjs 전역/인스턴스 로케일 미변경** — 소비자의 다른 dayjs 사용에 영향 없음.

## 검증

테스트 프레임워크 없음(라이브러리 제약) → 검증은:
1. `yarn typecheck` 0 에러 (`CalMessages`·`messages` 옵션·`useCalI18n` 타입 정합).
2. `yarn build` 클린 + `dist/index.d.ts`에 `CalMessages` export.
3. 플레이그라운드로 `locale: 'en'` 렌더 → 라이브러리 UI 텍스트에 한국어 미노출 육안 확인(요일 헤더·툴바·뷰 pill·제목·툴팁 라벨·빈 상태·+N 더보기·시각 표기), `locale: 'ko'`가 현재와 동일함 확인.
4. `messages` 부분 오버라이드 1건(예: `today: '금일'`) 반영 확인.
