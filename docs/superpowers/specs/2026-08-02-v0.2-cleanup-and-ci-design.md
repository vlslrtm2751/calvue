# calvue 0.2.0 정리 + CI 설계

**목적:** ① 선언만 있고 동작하지 않는 공개 API 3종(`headerToolbar`·`rrule`·`more`)을 제거하고, `event-move`/`event-resize` 페이로드를 공식 타입(`CalEventChange`)으로 확정해 **0.2.0**을 배포한다. ② 모든 push/PR에서 `typecheck`+`build`를 자동 실행하는 **GitHub Actions CI**를 구축한다.

## 진행 순서 (승인된 결정)

1. **CI PR** (`ci-workflow` 브랜치): 워크플로 파일 + README 배지 2개(npm·CI) 추가 → 먼저 머지되면 이후 PR이 CI 검증을 받는다.
2. **API 정리 PR** (`v0.2-api-cleanup` 브랜치, CI PR 머지 후 main에서 분기): API 제거·타입화·README 표 동기화·버전 0.2.0.
3. 머지 후 사용자가 `npm publish`(OTP) — npm 페이지의 README(배지·표)도 이때 함께 갱신된다.

- 기존 로컬 전용 `readme-npm-badge` 브랜치(`c5cffbf`)는 **폐기** — 원격 미push 확인됨(2026-08-02). npm 배지는 CI PR에 포함한다.
- 이 환경의 권한 패턴: 커밋까지 이 세션이 수행, **push/PR 생성은 사용자**(커맨드·링크 제공).

## 작업 A — CI

`.github/workflows/ci.yml` 신규:

- 트리거: `push`(main 브랜치) + `pull_request`
- `ubuntu-latest`, **Node 22**(로컬 v22.14.0과 일치), `actions/setup-node@v4`의 yarn 캐시
- 스텝: `yarn install --frozen-lockfile` → `yarn typecheck` → `yarn build`
- 시크릿 불필요. npm 자동 배포는 범위 밖(추후 도입 시 granular access token 사용).

README 헤더 배지줄 확장:

- npm 버전 배지: `[![npm](https://img.shields.io/npm/v/calvue.svg)](https://www.npmjs.com/package/calvue)`
- CI 배지: `[![CI](https://github.com/vlslrtm2751/calvue/actions/workflows/ci.yml/badge.svg)](https://github.com/vlslrtm2751/calvue/actions/workflows/ci.yml)` — PR 시점엔 워크플로가 main에 없어 배지가 깨져 보이며, 머지 후 정상 렌더된다(허용).

## 작업 B — 0.2.0 API 정리

전부 no-op 제거라 **런타임 동작 변화 없음**. 타입 차원에서만 breaking(pre-1.0 minor로 배포).

신설 타입([src/types.ts](../../src/types.ts)):

```ts
/** event-move/event-resize 페이로드. start/end는 변경 후의 새 값 (end는 배타적 종료). */
export interface CalEventChange {
  ev: CalEvent;
  start: Dayjs;
  end: Dayjs;
}
```

파일별 변경:

- `src/types.ts` — `CalOptions.headerToolbar` 삭제, `CalEventInput.rrule`·`CalEvent.rrule` 삭제, `CalEventChange` 신설.
- `src/components/cal-calendar.vue` — `DEFAULT_CAL_OPTIONS.headerToolbar` 삭제; emits에서 `more` 삭제, `eventMove`/`eventResize`를 `[CalEventChange]`로; 템플릿의 `@more` 중계 삭제; `CalEventChange` type import 추가.
- `src/components/internal/cal-month-view.vue` — emits `more` 선언 삭제, `eventMove`/`eventResize` `[unknown]`→`[CalEventChange]` (+type import).
- `src/components/internal/cal-time-grid.vue` — emits `[unknown]`→`[CalEventChange]` (+type import).
- `src/normalize.ts` — `rrule: input.rrule,` 라인 삭제.
- `src/index.ts` — export type 목록에 `CalEventChange` 추가.
- `package.json` — `"version": "0.2.0"`.
- `README.md` — CalOptions 표에서 `headerToolbar` 행 삭제(23개→22개 필드), CalEventInput 표에서 `rrule` 행 삭제, 이벤트 표에서 `more` 행 삭제, `event-move`/`event-resize` 행을 `CalEventChange` 페이로드 설명으로 교체("소스 확인 필요" 문구 제거). 결과: README에서 "현재 미적용"·"현재 미발생" 0건.

## Release 노트 초안 (GitHub Release용 — CHANGELOG.md는 도입하지 않음)

> **Breaking (타입 전용 — 런타임 동작 변화 없음)**
> - `CalOptions.headerToolbar` 제거 — 선언만 있고 어디에도 적용되지 않던 옵션입니다.
> - `CalEventInput.rrule` / `CalEvent.rrule` 제거 — 값이 보존만 되고 반복 일정 전개 로직이 없었습니다. 데이터를 유지해야 하면 `extendedProps`에 담으세요.
> - `more` 이벤트 선언 제거 — 발생하는 코드가 없었습니다(`+N 더보기`는 내장 팝오버로 동작).
>
> **Added**
> - `CalEventChange` 타입 — `event-move`/`event-resize` 페이로드가 `{ ev, start, end }`로 공식화되어 자동완성·타입 검사가 가능해졌습니다.
> - GitHub Actions CI — 모든 push/PR에서 typecheck+build.

- `yarn play` 렌더 스모크(월/주 스크린샷 확인).
- grep: `src/`와 `README.md`에서 `headerToolbar`·`rrule` 0건, `more` emit 선언(`more: [`·`@more`) 0건, README `현재 미적용`·`현재 미발생` 0건.
